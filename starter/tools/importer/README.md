# Importer

Import rules for migrating legacy content into EDS. See docs/15-migration-utilities.md
for the full workflow (inventory -> rules -> bulk import -> content QA -> redirects ->
parity check -> cutover).

Run via the Helix Import UI (https://www.aem.live/tools/importer/) pointed at `import.js`,
or the `@adobe/helix-importer` CLI for bulk runs.
